Creating a basic zomato like application with kafka and docker integration

Created a system design diagram of what to have in the application:
1) Functional Requirements :
   * Order the food
   * View restaurant upto some x kms(distance from where the food can get delievered practically).
   * View menu
   * Search functionality(based on food, restaurant, etc)
2) Non-functional requirements:
   * Consistency>>Availability
   * Order placed in minimum time.
